# Маршрутник

Веб-приложение для построения маршрутов развозки. Карта Яндекса, точки с весом груза, выбор «что везём сегодня», старт/финиш, оптимизация порядка объезда, открытие в Я.Картах для навигации.

## Запуск локально

```sh
python3 -m http.server 8000
```

Открыть в браузере: <http://localhost:8000>

(Открывать `index.html` напрямую через `file://` тоже работает, но через HTTP надёжнее — Я.Карты иногда капризничают на file-протоколе.)

## Настройка API-ключа

Ключ нужен для Яндекс Карт. Получить здесь: <https://developer.tech.yandex.ru/services> (нужны **JavaScript API** + **HTTP Геокодер**, бесплатный лимит — 1000 запросов в сутки).

Способы задать ключ:
1. **Файл `config.local.js`** (для разработки) — скопировать из `config.example.js` и вставить ключ. Файл в `.gitignore`, секрет не утечёт.
2. **Через UI** — нажать «⚙» в углу приложения, вставить ключ. Сохраняется в localStorage браузера.

`.env` хранит ключ как заметку для документации — браузер его не читает, его подхватывает только `config.local.js`.

## Деплой

Любой статический хостинг: GitHub Pages, Vercel, Netlify, Cloudflare Pages. Закинул три файла (`index.html`, `styles.css`, `app.js`) — работает. Ключ в `config.local.js` нужно положить рядом, либо использовать UI на стороне пользователя.

## Что есть

- Добавление точек: клик по карте или поиск по адресу.
- Редактирование: название, адрес, вес груза.
- Чекбокс «везём сегодня» — фильтрует точки для маршрута.
- Выбор точки старта и финиша (если финиш не задан — возвращаемся в старт).
- Кнопка **Построить маршрут** — оптимизирует порядок объезда (nearest-neighbor), показывает расстояние и время.
- Кнопка **Открыть в Я.Картах** — отправляет маршрут в полноценные Я.Карты для навигации в дороге.
- Всё хранится в localStorage браузера — между сессиями не теряется.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `app.js` — вся логика
- `config.local.js` — API-ключ (gitignored)
- `config.example.js` — шаблон конфига
- `.env` — заметка с ключом (не используется браузером)
